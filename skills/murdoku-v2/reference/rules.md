# 基础规则

## 1.1 目标

把 K 个角色放到案发现场，其中有一个是凶手，用线索推出每个人所在的位置，最终确定是谁杀了被害者。

## 1.2 放置规则

K 名角色各出现且只出现 1 次，且K个格子每行每列只出现一次。

R表示纵列，C表示横列
K

## 1.3 格子可用性（可放 / 不可放）

角色只能放在可用的地砖格上。

**可用性字典（累积维护，新结论一律回写本表）**

| 元素 | 可否放人 | 
|---|---|---|---|
| 空地砖格 | ✅ 可放 | 
| 椅子 | ✅ 可放 | 
| 桌子 | ❌ 不可放 |
| 树木 | ❌ 不可放 | 
| 花丛 | ❌ 不可放 | 
| 未收录元素 | ❓ | 

## 1.4 房间（Room）

- 盘面被粗线划分成若干房间，形状不规则。
- 房间不限制人数；它是下列判定的作用域：位置线索、"旁边"的必要条件、角落线索、全局人数线索、凶手判定。
- 同一个房间内部可以有不同地面（草地/地砖/粉色过道），**不要用地面颜色判断房间边界**。

## 1.5 凶手判定

游戏原文：凶手曾与被害者单独在一起（处于同一区域）。关键词"单独与"= 房间里只有这些人。

- 被害者（Vikram）所在房间恰好 2 人（被害者 + 1 人）→ 那 1 人即凶手。
- 房间里 1 人或 ≥3 人 → 前面解错了，回头查。
- **凶手不是"最后剩下的那个人"，也不是"正交相邻的那个人"**。
