# 常见错误对照

| 错误 | 正确做法 |
| --- | --- |
| 主 agent 自己作答 | 用干净 subagent，只传 prompt |
| 作答 subagent 附带参考答案 | 只传 prompt |
| 作答 subagent 读题库/参考答案文件 | 永远禁止，只基于传入的 prompt |
| 未标记 allow_search 的题目联网搜索 | 仅 `allow_search: true` 的题目才允许调用 tavily；未标记题不联网 |
| 对模型输出改写、润色、评判 | **原样保存** |
| 臆造被测模型名 | 询问用户确认（注意代理别名） |
| 报告缺某一部分 | 四部分固定：平台模型 / 免责声明 / 各题输出 / 总结 |
