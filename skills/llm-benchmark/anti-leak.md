# 防泄题关键规则（不可违反）

作答 subagent 的输入必须是干净的，这是「如实记录」的前提——否则记录的不是模型的独立反应，而是参考答案的复述：

| 借口 | 现实 |
| --- | --- |
| 「主 agent 直接作答更快更省事」 | 主 agent 已读过题库全文，上下文已污染，记录的是照着参考答案的复述，不是模型真实反应 |
| 「把参考答案给作答 agent 更准确」 | 泄题。作答 agent 只能看到 prompt |
| 「作答 agent 自己读一下题库更准确」 | 读题库 = 看到参考答案 = 泄题。**读题库文件永远禁止**，作答 agent 只基于传入的 prompt |
| 「联网检索和读题库差不多」 | 不同：联网（tavily）检索的是公开网络资料，**仅限 `allow_search: true` 的题目**；未标记题禁止联网，任何情况下都不读题库/参考答案文件 |
| 「一次跑完全部题再统一处理」 | 每道题必须是独立的干净上下文，才能如实反映该题水平 |

**违者重做：** 若发现作答时看到过参考答案，丢弃该作答，用干净上下文重新执行该题。
